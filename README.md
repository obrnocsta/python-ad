> Estudos de Python para Análise de Dados da Turma 05 da Generation Brasil.

## 📌 Sobre o projeto

Este repositório reúne exercícios e pequenos projetos desenvolvidos durante a jornada de aprendizagem em Python. O objetivo é praticar lógica de programação, estrutura de dados, fluxo de execução e criação de soluções simples usando a linguagem Python.

## 🗂️ Estrutura do repositório

| Pasta | Conteúdo |
| --- | --- |
| `01-hello` | Primeiros scripts em Python, como saudações e textos simples. |
| `02-variaveis` | Exercícios sobre variáveis e entrada de dados. |
| `03-toy` | Projeto de história interativa (Mad Lib). |
| `04-shopping-list` | Lista de compras com lógica básica. |
| `05-fluxos` | Estruturas condicionais e laços: tabuada, notas, senha, fizz buzz e listas. |
| `07-funcoes` | Prática com funções e manipulação de data/hora. |
| `08-todo-list` | Aplicação de lista de tarefas. |
| `09-calculadora` | Calculadora simples com operações matemáticas. |
| `git-guide.md` | Guia de uso do Git e GitHub. |

## 🧠 O que foi praticado

- Variáveis e tipos de dados
- Entrada e saída de dados
- Condicionais e estruturas de decisão
- Laços de repetição
- Funções e modularização
- Listas e organização de dados
- Lógica de programação aplicada em pequenos projetos

## ▶️ Como executar um arquivo

Entre na pasta do exercício e rode o script com Python:

```bash
cd 01-hello
python hello.py
```

Ou, se preferir executar diretamente:

```bash
python 01-hello/hello.py
```
